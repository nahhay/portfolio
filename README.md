# Portfólio Pessoal

Portfólio desenvolvido para reunir meus projetos, conhecimentos técnicos e um pouco da minha trajetória na programação.

O layout foi criado por mim no Figma e desenvolvido utilizando HTML, CSS e JavaScript, mantendo uma interface minimalista, com foco na organização e apresentação dos conteúdos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Figma

## Sobre o projeto

O portfólio está dividido em cinco seções:

- **Início:** apresentação pessoal e navegação.
- **Sobre:** minha trajetória e meu interesse pelo desenvolvimento de software.
- **Habilidades:** linguagens, tecnologias e ferramentas que utilizo.
- **Projetos:** sistemas desenvolvidos, com descrições e links.
- **Contato:** acesso ao GitHub, LinkedIn e currículo.

Na seção de projetos, reuni três sistemas principais: gerenciamento de estoque, controle financeiro pessoal e gerenciamento de caixa comercial. Também incluí uma área adicional para outros projetos e estudos.

O site foi desenvolvido inicialmente para a resolução de 1980 × 1080, seguindo as dimensões utilizadas no Figma, sem adaptação responsiva para outras telas.

## Estrutura

```text
├── assets/
├── index.html
├── style.css
└── script.js
```

O HTML organiza o conteúdo, o CSS define a aparência e o JavaScript controla a interação da janela de projetos adicionais.

## Execução

Para visualizar o portfólio localmente, basta abrir o arquivo `index.html` no navegador ou utilizar a extensão Live Server no VS Code.

Não é necessário instalar dependências.
